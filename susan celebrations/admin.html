Recent Booking Enquiries (this device only)

These are enquiries submitted from your booking form on this same browser. They won't include enquiries submitted by visitors on other devices — see below for a way to capture those centrally.

Want enquiries from every visitor, from anywhere?

That needs a tiny free backend. The easiest option: a free Google Sheet that logs every submission automatically. Steps:

  1. Create a new Google Sheet, then go to Extensions → Apps Script.
  2. Paste the script below, replacing the sheet name if needed, and click Deploy → New deployment → Web app (access: "Anyone").
  3. Copy the deployment URL it gives you.
  4. Send me that URL and I'll wire your booking form to POST enquiries straight into your sheet.
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const d = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), d.name, d.phone, d.email, d.type, d.date, d.guests, d.notes]);
  return ContentService.createTextOutput("OK");
}
